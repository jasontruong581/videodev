# EP001 — API là gì? Hiểu qua một lần gọi món

Trạng thái: scripted_reference. Bản nháp từ định hướng cũ, chưa được chủ kênh chọn làm tập đầu. Chưa có voice/render/phụ đề đã căn thời gian. Giọng dùng cho các tập mới đã chốt Hải Đăng; chọn nội dung từ menu mới trước sản xuất.

Khán giả: người mới học lập trình và AI. Sau video, người xem giải thích được API là cách phần mềm giao tiếp theo quy tắc, phân biệt request và response. Thời lượng mục tiêu: 75–90 giây, phải đo lại theo giọng thật.

Hook: “Bạn nghe API suốt, nhưng nó thực sự làm gì?”
